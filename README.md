# notesurfing.com

Sitio estático de NoteSurfing, publicado con GitHub Pages desde `main` (dominio en `CNAME`).

- `/` y `/en/`: página de inicio (ES / EN)
- `/privacy`, `/terms`, `/support`: URLs registradas en App Store y Google Play. **No renombrar ni borrar.**
- `/privacidad`, `/terminos`, `/soporte`: versiones en español
- Estilos compartidos en `assets/site.css`
